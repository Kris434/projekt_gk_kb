# Projekt z grafiki inżynierskiej

Projekt zrobiony w technologii C++. Została użyta biblioteka OpenGL do stworzenia układu ziemia - księżyc wraz z satelitą. Ziemia oraz księżyc obracają się wokół własnej osi, księżyc krąży wokół ziemi.
Na wszystko nałożone są tekstury, oraz dodatkowo ustawione jest oświetlenie całej sceny. 

Kamera jest ruchoma, co pozwala na dokładniejszą obserwację całego układu.
